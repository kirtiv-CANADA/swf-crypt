# SWF Crypt - Design

- Theme: dark crypt. Charcoal background, bone-white text, one accent color
  (ember orange or sickly green, pick one and stay consistent).
- Typography: serif display font for headings (for example Cinzel), Inter for body.
- Components: tombstone cards, an "autopsy report" layout styled like a medical
  record, and a "Resurrect" button with a short ritual animation.
- Accessibility: WCAG AA contrast, visible focus states, keyboard navigable,
  respect `prefers-reduced-motion`.
- Motion is subtle (fog, flicker). Never block content behind an animation.
- Only use assets that are self-made or have a free license.
- Status badges: Resurrected / Haunted / Beyond repair.
